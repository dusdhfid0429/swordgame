# 동작별 스프라이트 시트 (2026-10-21)

소스: 동훈님이 올린 마젠타 배경 시트 6장 (2948~2953). 회색 배경 6장(2942~2947)은 같은 동작의 이펙트·무기 포함본이라 참고용, 2954(어두운 배경 아틀라스)는 라벨이 없어 사용하지 않음.

## 규격
- 동작마다 가로 스트립 PNG 1장, 투명 배경
- 모든 동작 공통 셀: 186 x 348 px (점프 최고점까지 들어가는 높이)
- 발 기준선: 셀 아래에서 8px 위 (y=340), 가로는 셀 중앙. 점프·대시처럼 뜨는 컷은 원본 행의 바닥선 기준 높이를 그대로 유지
- 같은 이름의 .json: 프레임 좌표, 피벗, 원본 시트 위치, 마커 좌표(green = 손·그립, blue = 타격점·발 위치)
- preview/: 동작별 GIF(8fps 근처), 전체 미리보기 PNG

18 고속회피 7 · 19 통나무균형 8 · 20 폭포 기마자세 8 · 21 충격버티기 8

## 처리 과정 (scripts/)
1. unwm.py: 오른쪽 아래 Gemini 반짝이 워터마크를 반투명 역연산으로 걷어냄 (툴은 캐릭터에 겹친 워터마크를 못 지움)
2. extract.js: 스프라이트 툴(sprite_custom_studio.html)을 헤드리스 브라우저로 열어 시트를 넣고, 툴이 검출한 동작 그룹·컷을 그대로 꺼냄 (마커 숨기기만 끔)
3. compose.py: 어두운 초록·푸른 마커 제거(위치는 JSON에 기록), 분홍 잔상 제거, 붙은 캐릭터 분리, 공통 셀·발 기준 정렬로 시트 생성

## 알려진 한계
- 원본에서 이펙트만 있던 칸(검 쾌자 4번째 잔상, 대시 파란 돌진 등)은 마젠타 시트에서 빠져 있어 회색 시트보다 프레임이 적음
- 통나무 균형의 통나무는 마젠타 시트에 없음 (발 아래 마커만 있음)
- 마커가 있던 손 부위는 주변색으로 메워 약간 어둡게 보일 수 있음
