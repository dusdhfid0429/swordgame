# 천하대전 스토리 설계 (1단계: 엔진)

사용자 구상 (2026-10-13): 생마다 정해진 나이에 천하대전이 터지고, 그 구도는 그 전까지의 플레이로 정해진다. 윤회하면 타이머는 되돌아가지만 세상은 그대로 이어진다. 변하지 않는 중요 사건 10개가 있고, 푸는 방식이 뒤의 이야기에 영향을 준다. 전체 계획은 Claude Doc「강호윤회록 천하대전 스토리 구현 계획」.

## 시간표 (사용자 결정)

| 나이 | 단계 | 내용 |
|---|---|---|
| 8세 | 성장 | 태어난다. 무공·문파·생활에 집중하는 구간 (12년 ≈ 30분) |
| 20 ~ 24세 | 사건 | 반년마다 사건 하나, 아홉 개 (20, 20.5, … 24세) |
| 24 ~ 26세 | 전야 | 25.5세에 열 번째 사건 「결전 전야」 |
| 26세 | 천하대전 | 그해에 터진다. 전투·점령은 다음 단계 |

타이머는 생 기준이다. 대전 전에 죽으면 8세로 윤회해 처음부터 다시 겪되, 세상 상태는 이어진다.

## 세상 상태 (생을 넘어 남는 것)

`G.W = {pow:{정,사,마,관}, rel:{정사, 사마, 정관}}`, `G.seal`(봉문한 문파), `G.occ`(점령, 4단계), `G.wars`(지난 대전). 처음 값은 `data/story.json` STORY.INIT (정 50 · 사 40 · 마 30 · 관 40, 정사 -20 · 사마 0 · 정관 +20). 타이틀의 **처음부터 새로**만 이것들과 강호사를 지운다 (`G0()`).

움직이는 것: 사건의 선택(fx), 문파·맹 임무 보고(그 세력 +1 / +1.5), 세력 무인 처치(고수 -1, 무인 -0.3), 해마다 마교 +2 (STORY.DRIFT), 지난 대전의 패자 해마다 +1.

## 구도 규칙 (STORY.WAR, 순서대로 처음 맞는 것)

1. 정사 ≥ +20 이고 마교 힘 ≥ 45 → 정사연합 대 마교
2. 사마 ≥ +20 이고 정사 ≤ -20 → 사마연합 대 정파
3. 정사 ≤ -40 이고 사파 힘 ≥ 60 → 정마밀약 대 사파
4. 아니면 삼파전

관군: 정관 ≥ 30이면 정파 쪽에 선다, 관군 힘 ≥ 70이면 '관군 토벌'로 따로 선다. 마교 힘 < 25면 빠진다. 남는 쪽이 하나면 '중재'.

## 사건 (STORY.EV)

각 사건은 `{id, age, n, t, ch:[3]}`. 선택은 `{n, d, req, fx, quest, done}`:
- `req`: 조건 줄 목록. 모두 맞아야 한다. 한 줄 안의 `|`는 '또는'. 키: `pow.정`, `rel.정사`, `fame`, `good`, `evil`, `karma`, `realm`, `side`, `fac`(내 편), `sect`, `lives`, `pick.ev1`, `flag.x`. 연산 `>= <= == != in:a,b`.
- `fx`: 고르자마자. `pow`, `rel`, `fame`, `good`, `evil`, `silver`, `powSelf`(내 편의 힘), `flag`, `seal:{side,n,tier}`, `unseal`.
- `quest`: 처치 임무 (`P.quests`에 `story`·`ci`를 달아 들어간다). 정세 창의 사건 카드에서 보고하면 `done` fx.
- 세 번째 선택은 조건 없는 기본이다. 고르지 않은 채 다음 사건이 오면(마지막 사건은 26세가 되면) 기본으로 흘러간다.

| 나이 | 사건 | 선택 |
|---|---|---|
| 20 | 혈교의 그림자 | 토벌(임무) / 밀서 전달(사파·악업) / 모른 척 |
| 20.5 | 마교의 사신 | 호위(임무) / 벤다(임무) / 사천맹에 밀고 |
| 21 | 천하비무대회 | 출전(삼류, 임무) / 어지럽힌다 / 구경 |
| 21.5 | 봉문 위기 | 막는다(정·관, 임무) / 밀어붙인다(봉문) / 지켜본다(봉문) |
| 22 | 사파 분열 | 진압(사파, 임무) / 부추긴다(임무) / 관여 안 함 |
| 22.5 | 맹주 회의 | 연합 설득(명성 40) / 깬다(마교·악업) / 참관 |
| 23 | 황제의 칙령 | 받든다(정·관, 임무) / 맞선다(임무) / 몸을 사린다 |
| 23.5 | 본산 침공 | 탈환전(임무) / 가담(마교·악업, 임무) / 피한다 |
| 24 | 이간의 밤 | 파헤친다(명성 60/이류, 임무) / 올라탄다 / 흘려듣는다 |
| 25.5 | 결전 전야 | 전열에 선다 / 중재(명성 120·선업 60) / 몸을 피한다 |

## 코드

- `src/g_story.js`: `wld()` 세상 상태, `condOk`/`applyFx`, `warPlan()`, `tick` 훅(사건 열기·미루기·26세 발발), `newYear`/`kill`/`questDone`/`died`/`gLoaded` 훅, 정세 창 `pStory`(N 키, ☰ 메뉴 '정세', 인물 창 카드), `spick:ev:i` 동작.
- 새 훅: `tick`(dt), `questDone`(q), `died`(entry). `openPanel`의 창 목록에 `story`.
- `g_core.js`: `G0()`로 G 기본값, `newLife`는 8세·`P.story`. `g_sect.js joinBlock`: 봉문 문파는 거절.
- 저장 v3 (`g_save.js`): `G.W/seal/occ/wars`, `P.story`. 옛 저장은 이미 지난 사건을 '지나감'(-1)으로 적는다.
- 죽을 때 `G.history[].story = {pick, war}` → 다음 생의 사건 카드에 '전생의 흔적'.
- 테스트 `tests/t57_story.js`. 나이에 따라 바뀌는 임무 목록을 쓰는 t44는 13세로 맞춘다.
