# 강호윤회록 앱인토스 출시 점검 (2026-10-07)

앱인토스 개발자센터 문서를 읽고, 지금 게임과 비교해 정리했습니다. 출처는 맨 아래에 있습니다.

## 1. 동훈님이 직접 하셔야 하는 일

| 할 일 | 내용 |
|---|---|
| 앱인토스 콘솔 가입 | 워크스페이스 만들기 → 앱 등록 → 검수 요청 순서. 앱 이름(appName)은 한 번 정하면 못 바꿉니다. |
| 게임물 등급분류 | 게임은 등급분류 없이 출시할 수 없습니다. 게임물관리위원회 서류나 스토어 링크가 필요합니다. 방법: https://toss.im/apps-in-toss/blog/game_rating_classification |
| 사업자 등록 여부 결정 | 사업자 없이도 출시는 됩니다. 다만 인앱 광고, 인앱 결제, 토스 로그인은 사업자 등록이 있어야 쓸 수 있습니다. |
| 검수 기간 | 앱 등록 1~2영업일, 출시 검수 3~5영업일. 게임은 전체 2~4주 정도라고 합니다. |

참고: 앱인토스 이용자는 만 19세 이상입니다.

## 2. 게임 코드에서 바꿔야 하는 것 (제가 할 수 있는 일)

| 항목 | 지금 상태 | 해야 할 일 |
|---|---|---|
| SDK 포장 | HTML 한 파일 | `@apps-in-toss/web-framework` + `granite.config.ts`(게임은 `webViewProps: { type: 'game' }`) + Vite 빌드로 `.ait` 번들 만들기 |
| 토스 상단 바 | 없음 | 게임은 오른쪽 위에 토스가 ··· 와 X 버튼을 띄웁니다. 지금 그 자리에 미니맵과 ☰ 메뉴가 있어 겹칩니다. 자리를 옮겨야 합니다. |
| 안전 영역 | 일부만 처리 | 아이폰 다이내믹 아일랜드 등 Safe Area를 침범하면 안 됩니다. |
| 화면 방향 | 세로·가로 둘 다 | 하나로 정해 그대로 동작해야 합니다. 세로 고정을 추천합니다. |
| 뒤로 가기 / 종료 | 처리 없음 | 안드로이드 뒤로 가기로 창 닫기 또는 종료, 종료할 때 확인 창이 필수입니다. |
| 소리 | 소리 없음 | 체크리스트가 배경음·효과음·진동 적용을 확인합니다. 넣는다면 켜기/끄기 설정과 백그라운드 전환 시 정지가 필수입니다. |
| 저장 | 브라우저 localStorage | 플레이 기록이 나갔다 다시 들어와도 유지돼야 합니다. 토스 SDK의 저장소나 사용자 식별키에 묶어 저장하는 쪽으로 바꿔야 안전합니다. 기기를 바꿔도 유지하려면 서버가 필요합니다. |
| 첫 화면 | 약 0.7MB, 구글 폰트를 외부에서 불러옴 | 10초 안에 열려야 합니다. 폰트를 번들에 넣어 외부 요청을 없애는 게 좋습니다. |
| 외부 링크·iframe·eval | 없음 | 문제 없음 |
| 로그인 | 없음 | 토스 로그인만 허용. 지금처럼 로그인 없이도 됩니다. |

## 3. 내용 심사 관련

- 무협 액션은 허용됩니다. 피가 보이는 정도의 폭력(2단계)은 입장 전 경고 화면 대상이고, 잔혹 묘사(3단계)는 출시 불가입니다. 지금 게임은 피 묘사가 없어 1단계로 보입니다(제 판단).
- 수익화는 앱인토스 자체 광고(전면·보상형·배너)와 인앱 결제만 쓸 수 있습니다. 광고는 로딩·인트로 화면 금지, 미리 로딩, 보상형은 끝까지 봐야 보상 등의 규칙이 있습니다.
- '신영웅문 모작'이라는 표현은 출시 이름·설명에 쓰지 않는 편이 안전합니다. 시스템만 참고했고 이름·그림은 모두 새로 만든 것이지만, 원작 이름을 내세우면 분쟁 소지가 생깁니다(제 판단).
