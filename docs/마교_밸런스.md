| 관례 | 요지 |
|---|---|
| 성장 | "내공 축적 속도 = 마공 > 사파 심법 > 정파 심법", "한계점 = 정파 심법 > 마공 >>> 사파 심법". 마공은 초기 진척이 빠르지만 무학의 깊이가 얕아 높은 경지에 오르기 전에 미친다 (묵향 이후 정립). |
| 마기와 광증 | 마공은 마기를 함께 들이켜 "미치기 쉽고 주화입마에 취약". 단계 클리셰 입마 → 극마 → 탈마. 부정적 감정을 연료로 삼아 수련할수록 포악해지고 "이지를 상실하고 살육에 미친다". |
| 수련의 대가 | 제물(살생·피·정혈)로 빨리 강해진다. 급속 노화·통증·건강 악화. 역방향 운기로 주화입마. |
| 조문(약점) | 이음매가 약해 "정파식 내공 교정조차" 고경지 마공 고수에겐 주화입마를 일으킨다. 불가(역근경) 쪽이 마공의 천적. |
| 강호의 대우 | 마공 수련자는 범죄자로 취급되어 "비급을 지녔다는 이유만으로 무림공적·지명수배". 마교는 정·사 공통의 적이며, 사파와도 사상이 달라 함께 행동하지 않는다. |
| 교단 | 강자존·약육강식 무투파. 교주(천마)는 최강자가 차지한다. 규율 위반은 흑혈옥. 천마신공만이 "마공의 부작용을 뺀 심법". |
| 흡공 | 흡성대법: 이종진기 충돌로 발작, 흡수할수록 악화, 심장 부담으로 급사. |
| 주화입마 | 기 통제 실패. 원인: 운기 중 충격·과흡수·무리한 운용·심마. 증상: 발작 또는 **폭주**(주변을 가리지 않고 힘을 쏟아냄, 자아 상실). 방치하면 폐인·사망. 호법·연공실로 예방. |

## 2. 강호윤회록의 마교, 수정 전

| | 이점 | 대가 |
|---|---|---|
| 심법 | 내공 +25%/수련, 등급 천고(×2.2)까지, 특색 패도+흡혈 | 수련마다 악업 +1 (악업은 관군 적대·정파 대문파 가입 거부·이야기 분기 정도) |
| 속성 | 마기: 모든 속성에 1.3배, 적중 시 생명·내공 8% 흡수 + 둔화 | 불가 계열에 0.8배 |
| 경지 | 화경 마화경(생명 30% 아래 피해 +25%), 상한 효과 q .5·ult .6 | 폐관 -10%, 주화입마 무거움 45% |
| 세력 | 본산 8맵, 인원 증가 6%/년, 오당 비급 30% 할인 | 정·사 무인 모두와 적, 정파 출신은 산공 입마 |

이점은 "빠르고 강하다"는 관례와 맞지만, 대가는 숫자 몇 개뿐이라 마교답지 않았다.

## 3. 수정 (v104)

### 마성(魔性) — src/g_mara.js, data/simbeop.json MARA
마공 심법을 운용하는 동안 **마성** 0~100이 쌓인다 (`P.mara`). HUD에 검보라 게이지, 인물창에 카드.

| 오름 | 내림 |
|---|---|
| 내공 수련 1회 +3 · 살생 1명 +1 · 산공 입마 +20 | 운기조식 1초 -1.2 · 천마신전 **마기 정련** (공적 20 → -30) |

| 단계 | 마성 | 효과 |
|---|---|---|
| 평정 | 0~39 | 없음 |
| 입마 | 40~69 | 공격 +8%, 받는 피해 +8%, 양민이 "마인이다!" 하고 달아난다 |
| 극마 | 70~89 | 공격 +15%, 받는 피해 +15%, 싸움 중 초당 4% **폭주** |
| 광마 | 90~99 | 공격 +20%, 받는 피해 +20%, 초당 10% 폭주 |
| 100 | 주화입마 | 쌓은 내공 10%가 흩어지고 생명이 30%로, 마성 60으로 내려간다 |

- **폭주** 4초: 강제공격이 켜지고 자동초식으로 가장 가까운 것(같은 편 마교도·양민 포함)을 친다. 같은 편을 치면 배신·악업 규칙이 그대로 적용된다. 끝나면 강제공격이 원래대로.
- 마공을 버리면(정파 문파 입문 산공) 마성은 0이 된다.

### 한계: 깨달음 — g_realmfx.js gainEnl
"속성 수련에는 깨달음을 얻을 곳이 없다": 마공 운용 중 깨달음 ×0.5, 사공·사불 ×0.7. 깨달음은 무리 기둥이라 마공의 경지 상한이 실제로 낮아진다. (내공 +25%는 그대로: 빠르되 얕다.)

### 강호의 공적: 추살 — maraHunt
마교도가 명성 50 이상이면 해마다(마교 본산 밖에서) 정의맹·사천맹 무인 4명(고수 1)이 덮친다. 마교는 정·사 공통의 적이라는 관례.

### 그대로 둔 것
마기 상극 1.3배·불가 천적(v101), 내공 +25%, 산공 입마(v103), 폐관·주화입마 수치, 오당·8맵. 이점을 깎기보다 대가를 마교답게 만드는 쪽을 택했다.
