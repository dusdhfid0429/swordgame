# 무림전도 다시 읽기: 지역·문파·명소 특색 (2026-10-09)

사용자 요청: 이전에 공유한 TANMA 중국무림전도 v1.6을 다시 분석해서 지역별·문파별·명소별 특색이 있게 월드를 구성한다.
지도 범례: 주요도시 ◆, 명소 ●, 산이름 ▲, 주요문파 ◢, 성이름, 주요지형. 범례 항목은 이미 `data/world.json` `LM_DATA`(142곳)에 좌표째 들어 있고, 이 문서는 "그 자리가 어떤 곳인가"를 정리해 게임에 어떻게 담았는지 적는다.

## 4. 아직 안 한 것

- 명소마다 다른 사람(관문 수문장, 사당 제관, 포구 뱃사공)과 일거리.
- 성도마다 다른 특산(잡화점 품목)과 사투리 대사.
- 성 지도 자체의 명소 둘레 꾸미기는 전과 같다(이정표만).

## v155 지역별 지형 개성 (2026-10-19)

사용자 요청: "화산 같은 깎아지른 돌산… 실제 이미지를 확인한 다음 지역별 특색을 살려줘. 사막은 지형 효과, 물은 일렁거림. 성능도 먼저 파악."

- 표: `data/terrain.json`. `TERR.place`는 지명 조각(본산 자리·명산 이름·지역 이름에 들어 있으면 적용), `TERR.th`는 지역 테마 기본값(desert·gobi·karst·loess 등). `SPIRE`는 봉우리 그림 팔레트.
- 코드: `src/g_terrain.js`. `loadRegion`이 바닥을 굽기 전에 `regionGen` 훅을 부르고, 여기서 `TP`(지금 지역 지형), `WATER`(물 칸 목록)를 정하고 봉우리를 놓는다.
- 봉우리는 맵에 이미 있던 바위(와 화면 위쪽 가장자리 바위·나무)만 바꾼다. 막힌 칸 수가 그대로라 길찾기·출몰은 바뀌지 않는다(t92). 화면 아래쪽 세 줄은 시야를 가리니 바꾸지 않는다.
- 바닥 굽기(`bakeHQ`)가 TP의 바위 색·결(세로 절리/지층/둥근 풍화/돌부스러기), 풀·물 색, 구름바다 가장자리를 쓴다. 굽는 것이라 매 프레임 비용은 0.
- 화면 효과: 물 칸 반짝임(모든 맵), 떠도는 구름(cloud), 모래바람(sand), 아지랑이(heat, 맑은 낮만). 모두 한 번에 묶어 긋는 선이다.

|---|---|---|---|
| 화산·황산 | 회백 화강암, 세로 절리 | 칼날 봉우리 + 바위틈 소나무 | 구름바다 |
| 무당산 | 짙은 녹회색 편암 | 이끼 낀 봉우리 | 구름 |
| 아미산 | 현무암 지층 | 평평한 머리 | 흰 구름바다 |
| 숭산 | 황갈색 기운 지층 | 기울어진 결 | 황토 풀빛 |
| 곤륜·천산·대설산 | 돌부스러기 | 눈 덮인 봉우리 | 천산 청록 호수 |
| 장백산 | 화산암 | 눈 덮인 평평한 머리 | 짙푸른 천지 |
| 공동산·단하산·화염산 | 붉은 단하 사암 | 둥근 붉은 봉우리 | 화염산은 모래바람·아지랑이 |
| 명사산·감숙·신강 | 모래 | 낮은 야단(바람 깎인 지층) | 모래바람·아지랑이, 물가 밖 나무는 바위로 |
| 광서(카르스트)·장강삼협 | 석회암 | 둥근 기둥, 물때 자국 | 안개 |

성능(소프트웨어 렌더링, 390×844 @2x, 한 프레임): 효과를 켜고 끈 차이는 대부분 −1~+2ms다. 화산 21.2 vs 19.9ms, 공동산 15.8 vs 14.0ms, 감숙 9.0 vs 7.8ms, 보타산 13.4ms(물 반짝임 포함). 봉우리 그림은 팔레트마다 3장(약 100×230px)을 처음 쓸 때 만든다.

## 계절·날씨별 지형 모습 (v173, 2026-10-23)

사용자: "계절에 따라 나무나 바위 도로들 변경해줄 수 있어? 겨울이니깐 눈 덮인 소나무나 바위 관도 등 계절에 맞춰 날씨에 맞춰". 코드 `src/g_season.js`, 숫자 `data/season.json`(SEA), 테스트 `tests/t107_season.js`.

| | 나무(활엽·단풍나무) | 소나무·대나무·바위·봉우리·석탑 | 바닥 |
|---|---|---|---|
| 봄 | 앙상한 가지에서 새잎이 돋고, 연둣빛, 일부는 살구꽃 | 그대로 | 풀밭에 들꽃 |
| 여름 | 그대로 | 그대로 | 그대로 |
| 가을 | 단풍(나무마다 붉은·주황·노란 빛), 늦가을부터 잎이 진다 | 대나무 누렇게 | 마른 풀빛 + 낙엽 |
| 겨울 | 앙상한 가지 | 쌓인 눈만큼 윗면에 눈 | 쌓인 눈(관도엔 바퀴 자국, 물가 살얼음, 밭 고랑), 늦가을 낙엽은 초겨울에 사라짐 |

- 눈은 날씨가 쌓는다: 날씨가 '눈'이면 `G.snow`가 40초에 다 차고, 그치면 겨울엔 15분, 다른 계절엔 1분에 녹는다. 설산 테마 지역은 늘 0.85 이상, 사막은 0.3배.
- 비는 `G.wet`: 비가 오면 25초에 젖고 90초에 마른다(폭염 세 배). 젖으면 길·포석 칸 몇 곳에 물웅덩이가 생기고, 비가 오는 동안 빗방울 동그라미가 번진다.
- 나무는 칸마다 문턱이 달라 한 그루씩 차례로 물들고 진다(계절이 바뀌는 순간 숲 전체가 한꺼번에 바뀌지 않는다).
- 그림은 처음 쓸 때 한 번 만든다: 눈 겹은 원래 그림의 각 세로줄 윗면에 두께만큼 눈을 얹은 그림이고, 투명도(쌓인 양)로 덧그린다. 바닥은 구운 바닥 위에 반 해상도 겹(눈·낙엽·봄꽃)을 처음 필요할 때 굽는다(개봉 눈 겹 약 0.1~0.2초, 한 번). 조각 바닥은 한 프레임에 한 조각씩.
- 전각·동굴 안은 계절을 타지 않는다. 예전 화면 전체 색조(겨울 흰빛 .7, 가을 주황 .35)는 겹이 생겨 .35/.18로 줄였다.
