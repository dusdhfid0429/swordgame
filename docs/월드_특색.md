# 무림전도 다시 읽기: 지역·문파·명소 특색 (2026-10-09)

사용자 요청: 이전에 공유한 TANMA 중국무림전도 v1.6을 다시 분석해서 지역별·문파별·명소별 특색이 있게 월드를 구성한다.
지도 범례: 주요도시 ◆, 명소 ●, 산이름 ▲, 주요문파 ◢, 성이름, 주요지형. 범례 항목은 이미 `data/world.json` `LM_DATA`(142곳)에 좌표째 들어 있고, 이 문서는 "그 자리가 어떤 곳인가"를 정리해 게임에 어떻게 담았는지 적는다.

## 2. 문파별 특색 (`SECT_STYLE`)

| 갈래 | 문파 | 지붕 | 나무·소품 |
|---|---|---|---|
| 불가 | 소림사·아미파·보타문·대뢰음사·포달랍궁 | 황색 기와 | 마당 네 귀 석탑 |
| 도가 | 무당·화산·청성·종남·곤륜·전진·모산·고묘·태산·형산·공동·점창·천산 | 청록 기와 | 화산 매화, 청성·점창 대숲, 고묘·형산 단풍 |
| 세가 | 남궁·모용·팽·언·제갈·황보·악·당·양·단리·상관·단목·운 | 잿빛 기와(기본) | 장원 집 |
| 사파 산채·수채 | 녹림채·장강수로채·동정수로채·흑풍채·혈랑곡·야수궁·광풍사·만독문·하오문·귀영문·사마세가·개방 | 갈색 널 | 야수궁 대숲 |
| 변방 | 태양궁 | 주홍 | 화염산 붉은 바위 |
| 변방 | 북해빙궁 | 얼음빛 | 눈 |
| 마교 | 천마신교 | 검은 벽·붉은 기와 | 검은 땅 |

전각 이름(`HALLS`)도 문파마다 다르다: 화산파 자소궁·태청궁·장경각·옥천원·취운궁·매화봉 정자, 무당파 금전 태화궁·남암궁·옥허궁·복진관·자소궁·천주봉 정자, 소림사 대웅보전·장경각·달마원·나한당·계율원·달마정 등. 이름이 없는 문파는 파·교·문이면 삼청전·장경각·약왕전, 세가·장이면 정당·서재·연무청을 쓴다. 장문인·총관·장로·제자는 그 전각 안에 있다(`docs/세력_문파_설계.md` 19장).

호수(청해호·동정호·태호·서호·포양호·홍택호·소호·동호·북해)와 사막·초원·분지 같은 지형은 성 지도에 그대로 칠해져 있고 가까이 가면 이름이 뜬다.

## 4. 아직 안 한 것

- 명소마다 다른 사람(관문 수문장, 사당 제관, 포구 뱃사공)과 일거리.
- 성도마다 다른 특산(잡화점 품목)과 사투리 대사.
- 성 지도 자체의 명소 둘레 꾸미기는 전과 같다(이정표만).
