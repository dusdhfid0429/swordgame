# 강호윤회록

쿼터뷰 무협 브라우저 게임입니다. 엔진 없이 canvas 한 장으로 돌아가는 단일 HTML 파일입니다.

- 공개 버전: https://claude.ai/artifact/CFv5nS6GmLaCen2q9skDvA
- 그림은 모두 코드로 그렸고, 주인공 스프라이트는 직접 제공한 시트를 base64로 넣었습니다(`src/r_atlas.js`). 신영웅문 원작 에셋은 쓰지 않았습니다.

## 실행

`dist/gangho.html` 을 브라우저로 열면 바로 플레이됩니다. 저장은 브라우저 localStorage에 저장 칸 5개로 됩니다 (2026-10-14: 1번 칸은 `ganghoyunhoe-save-v1`, 2~5번은 `-1`…`-4`를 붙인 키, 마지막에 쓴 칸은 `ganghoyunhoe-slot`). 제목 화면 목록에서 칸을 고르면 이름·회차·나이·경지·문파·기록 시각과 이어하기·새 생·강호사·처음부터 새로 단추가 나오고, 지우기는 confirm() 대신 화면 안에서 한 번 더 묻습니다 (아티팩트·웹뷰에서 confirm이 막혀 안 눌리던 문제). 코드는 `src/g_life.js`(SLOT·setSlot·loadSlot)와 `src/g_screens.js`(showTitle·slotPanel), 테스트 `tests/t62_slots.js`. 저장에는 형식 번호 `v`가 붙고, 옛 저장은 불러올 때 `src/g_save.js`의 `MIGRATE`가 순서대로 옮깁니다. 저장 형식을 바꾸면 `SAVE_VER`를 올리고 옮기는 함수를 하나 더하세요.

## 수정 후 빌드

```
python3 build.py        # src/ 조각을 이어 dist/gangho.html 생성
```

`src/` 파일은 한 스크립트로 이어 붙여지므로 전역 이름이 겹치지 않게 주의하세요. 순서는 `build.py` 의 `PARTS` 에 있습니다.

다른 파일의 함수에 규칙을 더할 때는 함수를 감싸 덮어쓰지 말고 `hook('이름', 함수)`로 등록하세요. 핵심 함수가 정해진 자리에서 `runHooks`로 부릅니다. 훅 이름과 넘기는 값은 `src/g_core.js`의 "훅" 주석에 있습니다. 소리(`g_audio.js`)만은 결과를 듣기만 하는 관찰자라 예외로 감싸기를 씁니다.

## 테스트

```
npm i -D playwright && npx playwright install chromium
python3 build.py
node tests/run.js              # tests/t*.js 전부, 4개씩 나란히. 하나라도 실패하면 exit 1
node tests/run.js realm touch  # 이름에 realm·touch가 든 것만
node tests/run.js -j 1 -t 600  # 하나씩, 파일마다 600초 제한
node tests/run.js toss         # 가짜 토스 SDK로 앱인토스 대응 확인 (t4_toss)
```

각 테스트는 `PASS …`/`FAIL …` 줄과 마지막에 `no console errors` 또는 `ERRORS`를 찍습니다. 러너는 `FAIL` 줄, `ERRORS`, 0이 아닌 종료 코드, 시간 초과를 실패로 셉니다. 스크린샷은 `tests/shots/`(커밋하지 않음)에 남습니다.
GitHub에 푸시하면 `.github/workflows/test.yml`이 빌드, dist 일치 확인, 전체 테스트를 돌립니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `g_head.html` | CSS, 화면 DOM, 하단 패널 |
| `g_data.js` | 근골·신분·무기·오행·무공 생성·몬스터·직업·레시피 등 데이터 |
| `g_core.js` | 캐릭터 상태, 아이템, 전투 계산, 초식/연속기/필살기, 내공 수련, 길들이기 |
| `g_world.js` | 맵 생성(개봉 마을, 동굴, 산채, 농지, 집터), 좌표 변환, 바닥 굽기 |
| `g_life.js` | 갱신 루프, 이동/길찾기, 몹 AI, 상호작용, 농사·제작, 해 넘김, 죽음·윤회, 비무, 저장 |
| `g_ui.js` | 로그, HUD, 스킬 바, 각종 창(K/B/I/P/L/H), 상점·NPC 대화 |
| `g_screens.js` | 타이틀, 캐릭터 생성, 환생 화면, 입력 처리 |
| `g_touch.js` | 모바일 터치 조작: 조이스틱, 버튼 여섯 개, 메뉴 |
| `g_toss.js` | 앱인토스 대응: 세로 고정, 안전 영역, 뒤로 가기·종료 창, 토스 저장소 |
| `g_story.js` | 천하대전 스토리: 세력 힘·관계, 사건 10개와 선택, 정세 창, 구도 계산 |
| `g_pop.js` | 문파 인원: 해마다 증가, 무인 사망으로 감소, 세력의 힘·직위 분포·본산 맵 수가 인원을 따름, 출입구 충원 |
| `g_draw.js` | 그리기(날씨·계절·동굴 어둠), NPC·짐승·말, 미니맵, 메인 루프 |
| `r_*.js` | 이전 프로토타입 「흑풍채 토벌기」에서 가져와 고친 엔진 조각(초식 실행, 이펙트, 건물, 캐릭터 그리기) |

## 조작

휴대폰·태블릿에서는 터치 조작 화면이 자동으로 켜집니다. 왼쪽 아래를 끌어 이동하고, 오른쪽 아래의 큰 공격 버튼을 중심으로 보법(왼쪽)·필살(왼쪽 위)·경공(위)·비기·상황 버튼이 부채꼴로 놓입니다 (원신·명조식 배치, 2026-10-13 B안). 오른쪽 가장자리 세로 열의 네모 단추가 켜고 끄는 것들로, 아래부터 질주, 강제공격, 운기조식(싸움 중이 아닐 때), 승마·하마(말이 곁에 있을 때)입니다. 강제공격(PC는 T 키 또는 HUD '강제' 단추, 2026-10-13)을 켜면 같은 편 무인도 공격 대상이 되고 범위 초식에도 맞으며(양민은 직접 눌러야), 치면 그대로 배신이 되어 악업이 쌓입니다. 장문인 NPC도 강제공격을 켜고 클릭하면 우두머리로 나와 싸웁니다 (`docs/스토리_설계.md` 문파 인원). 출입구나 맵 가장자리는 1초 머물러야 넘어가고, 지나가거나 경공으로 날면 넘어가지 않습니다 (2026-10-13, `docs/맵이동_설계.md`). 금창약·소환단·비도(암기를 익혔을 때)는 퀵슬롯 줄에 있는데 세로 화면에서는 왼쪽 아래 모퉁이, 가로 화면에서는 아래 가운데입니다. ☰ 메뉴는 창 목록(인물·무공·행낭·동료·생활·임무·강호사·천하 지도·수련)과 설정 줄(기록·조작법·PC 조작·소리)만 담습니다 (2026-10-13 정리). 공격 버튼은 자동초식으로 익힌 초식을 차례로 잇고, 필살기는 자동으로 쓰지 않아 필살 버튼(PC는 S)으로 직접 씁니다 (2026-10-13). 조작법 창에서 PC 조작과 서로 바꿀 수 있습니다 (`src/g_touch.js`).

속성은 운용 중인 심법의 것입니다. 오행(화→금→목→토→수→화)과 양→음→뇌→양은 이기는 쪽 1.3배·지는 쪽 0.8배이고, 천마신교의 마기는 다른 모든 속성에 1.3배 우위이되 불가 계열(소림·아미·보타) 심법 상대에게는 거꾸로 0.8배를 주고 1.3배를 받습니다 (2026-10-14, `docs/경지_설계.md`). 마교(천마신교)는 정파·사파를 가리지 않고 받지만(2026-10-15, 명성 100 또는 악업 80 조건은 그대로) 정의맹·사천맹은 같은 성향만 받습니다. 문파에 들면 받는 입문공은 문파 등급과 상관없이 하승이고, 대문파의 두 번째 일반 무공은 상승, 고급 무공은 대문파 절정·중견·군소 상승입니다 (`docs/세력_문파_설계.md` 26장).

천하대전 스토리(2026-10-13): 8세에 태어나 20세부터 반년마다 사건 10개가 열리고 26세에 천하대전이 터집니다. 정세 창(N, ☰ 메뉴 '정세')에서 세력의 힘·관계·예상 구도를 보고 사건의 선택을 고릅니다. 26세부터 세 해 동안 해마다 한 차례씩 결전(적 세력의 습격과 결전 임무)이 벌어지고, 이긴 편이 진 편의 본산 2곳을 점령하고 문파를 봉문시킵니다. 점령·봉문된 본산에서 탈환·개문 임무를 맡을 수 있습니다. 세력의 힘은 문파마다의 인원에서 나옵니다: 해마다 늘고 무인이 죽으면 줄며, 인원이 줄면 본산 맵이 닫히고 0이면 멸문합니다. 세력 무인은 맵 상한의 60%만 서 있다가 죽으면 출입구에서 걸어 들어와 충원됩니다. 인원이 기준의 절반 이하거나 줄어드는 문파는 장문인이 직접 싸우는 우두머리로 서고, 쓰러뜨리면 인원 10%가 흩어지며 3년간 장문인 자리가 빕니다. 세력 구도·봉문은 윤회해도 이어지고 타이틀의 '처음부터 새로'만 지웁니다. 설계: `docs/스토리_설계.md`.

PC: 클릭 이동·공격 / 초식 Q A Z E D C (넘버패드 7 4 1 9 6 3) / 필살기 S / 특수무공 1~3 / 신공 V / 물약 4~5 / 경공 Space / 운기 X / 창 K B I P L H J(임무) / Esc 닫기
